# Sidahmed Ettih | Research Portfolio

A lightweight, static, single-page research portfolio built with HTML, CSS and vanilla JavaScript. No Python server, framework, external fonts, analytics or runtime service is required.

## Run locally

Open `index.html` in a browser. For local development, any static file server is sufficient.

## Publish free with GitHub Pages

1. Create or use a GitHub repository for the site.
2. Upload the contents of this folder to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will publish the static site at the repository's Pages address.

A custom domain is optional. GitHub Pages hosting for eligible public repositories is free; a separately purchased custom domain is not required.

## Structure

- `index.html` — the complete one-page site and all section content
- `assets/css/style.css` — layout, typography, responsive rules and section palette
- `assets/js/site.js` — mobile navigation and current-year footer
- `assets/img/favicon.svg` — favicon

The older section URLs redirect to their matching anchors in `index.html` for compatibility.
